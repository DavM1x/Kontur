# Сторонние компоненты

| Компонент | Источник и условия |
| --- | --- |
| libmpv для Windows | [mpv, исходный коммит d11ffba25](https://github.com/mpv-player/mpv/commit/d11ffba25). В сборку входит отдельная DLL из LGPL-выпуска mpv и сопровождающий файл `runtime/mpv/LICENSE.LGPL`. |
| Библиотеки ядра Rust | Версии зафиксированы в [Cargo.lock](../rust/Cargo.lock). Лицензии входят в установку в файле `ThirdParty-Rust.txt`. |
| Microsoft WebView2 | [Microsoft WebView2 SDK](https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.3912.50). Сборка содержит `runtime/webview2/LICENSE.txt` и `runtime/webview2/NOTICE.txt`. |
| Pixelify Sans | [Google Fonts](https://github.com/google/fonts/tree/main/ofl/pixelifysans). [SIL Open Font License](../assets/PixelifySans-LICENSE.txt). |
